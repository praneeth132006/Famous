# Veo / Flow prompt library

Paste-ready hook shots for the content queue. One per Reel, plus the house style that keeps the grid looking like one account.

**Flow settings for every clip:** Video · Omni 1.1 Flash · 720p · **8s** · **9:16** · **x1** = 12 credits.
Download at **1080p Upscaled**, which is exactly Reels resolution.

---

## House style

Append to every prompt. This is what makes ten unrelated videos read as one channel:

> `Dark near-black background. Electric lime green (#C6F432) as the only accent colour. Volumetric fog and floating dust motes. Dramatic single-source lighting, high contrast, deep shadows. Macro or close-up lens, shallow depth of field. Slow deliberate camera move. Photorealistic, cinematic, no text, no logos, no user interface.`

**"No text, no user interface" is not optional.** Veo renders fake UI and garbled text badly, and this account's entire promise is showing real output. Every interface and every word on screen gets composited afterwards from real captures. The generated footage carries mood and metaphor only.

## Generation batch order

Generate in this order so the highest-value Reels are ready first:
**R1 → R3 → R6 → R2 → R5**, then the rest. R3 and R6 have the widest send appeal in the queue, R1 is already done.

Five clips = 60 credits. All ten = 120 credits. Against a 1,050 credit balance, the whole queue costs about 11% of what is available, so there is plenty of room to regenerate anything that lands badly.

## Reminder on the watermark

Every Flow output carries a visible watermark that cannot be disabled in this region. For an account openly about AI tools this is defensible, arguably even on-brand. It is a real constraint to accept deliberately, not a surprise to discover after ten videos are cut.
